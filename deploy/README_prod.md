# AIOps 智能运维托管平台（Windows 部署包）

## 三步部署
1. 复制整个 AIOps-Windows 文件夹到目标服务器（路径不要含中文/空格）。
2. 双击 deploy\start.bat 启动，浏览器打开 https://localhost:8000（局域网用 https://本机IP:8000，首次访问提示证书不受信任时选「继续前往」）。
3. 如需开机自启：deploy\register_autostart.bat；如需注册为 Windows 服务：deploy\install_service.bat。

## 目录结构
```text
AIOps-Windows/
├─ AIOpsServer.exe      # FastAPI 后端（:8000，同端口托管前端）
├─ AIOpsService.exe     # Windows 服务宿主（可选）
├─ start.bat            # 快捷启动
├─ frontend/dist/       # 已构建前端
├─ backend/.env         # 环境配置（首次启动前按需修改）
├─ deploy/              # 启动/停止/自启/服务注册脚本
└─ tools/               # PostgreSQL 可选依赖（SNMP 采集已内置 pysnmp，无需 Net-SNMP）
``` 

## 首次登录
管理员账号 admin，初始密码已随机生成并写入 backend\.env 的 BOOTSTRAP_ADMIN_PASSWORD。
首次启动后请立即修改密码。

## 数据库
默认库 aiops / 用户 aiops / 密码 aiops123，可用 backend\.env 覆盖（如连接已有 PG）。

## 防火墙
放行 TCP 8000 入站；纳管设备需出站放行 SNMP 161 / SSH 22 / Telnet 23。

## 移动端 APP（Android）

平台附带原生 Android 手机 APP（APK），用于随时随地查看平台数据与接收告警通知。

### 安装
- 将 `app-release.apk` 复制到手机（或扫码/网盘分发），点击安装。
- 首次打开如提示「未知来源」，需在系统设置中允许安装该来源。

### 登录
1. 打开 APP，进入登录页。
2. 输入平台服务器地址（如 `<服务器IP>`，即 `https://<服务器IP>:8000`）与端口（默认 `8000`）。
   - 服务器地址支持「记住此服务器」，下次登录自动填充。
3. 输入平台账号密码（与桌面端一致），点击登录。

> 平台默认以 **HTTPS（自签名证书）** 提供服务，APP 已内置信任该证书，无需额外配置；请勿在未启用 HTTPS 的服务器上使用。

### 功能
| 模块 | 说明 |
|------|------|
| 监控概览 | 设备总数/在线/离线/告警统计、在线率、最近告警 |
| 设备 | 设备台账列表、详情（接口/流量/SNMP 信息） |
| 告警 | 告警列表与状态筛选（严重/重要/次要/警告中文分级） |
| 拓扑 | 网络拓扑视图，双击节点查看设备详情 |
| 更多 | 生命周期、等保合规、安全监控、设备巡检、账号设置 |

### 告警通知
- APP 登录后每 30 秒自动检查一次新告警。
- 发现「严重 / 重要」级别新告警时，在系统通知栏弹出通知。
- **首次使用请在系统设置中完全授权通知权限**：
  `设置 → 应用管理 → AIOps 智能运维 → 通知`，打开所有开关（仅 APP 内弹窗授权可能不完整）。

### 升级
- 替换新的 APK 安装包后覆盖安装即可，登录状态与服务器配置会保留。

## 升级（一键升级）

从厂商获取升级包 `aiops-upgrade-vX.Y.Z.zip` 后，在平台内即可完成一键升级，**无需手动替换文件**，升级会自动备份并**保留全部设备、告警与配置数据**。

### 网页一键升级（推荐）
1. 登录平台 → 「系统设置 → 系统升级」。
2. 上传官方升级包 `aiops-upgrade-vX.Y.Z.zip`。
3. 点击「一键升级」：平台自动执行 校验 → 备份程序/配置 → 备份数据库快照 → 停止服务 → 替换文件（保留 backend/.env）→ 启动新版本 → 健康检查。
4. 升级期间平台短暂停机（约 30~60 秒），完成后自动恢复；失败自动回滚到升级前版本。

> - 升级包通过 RSA 签名校验，仅接受官方升级包；非官方/被篡改的包会被拒绝。
> - `backend/.env`（含设备凭据加密密钥）升级时自动保留，覆盖安装后设备凭据仍可正常解密。
> - 升级前自动生成数据库快照（pg_dump），存放于 `upgrade/backup/`。

### 手动升级（备用）
替换 AIOpsServer.exe 与 frontend/dist 后重启即可；表结构由 init_db() 自动同步（表结构变更走内置迁移框架自动执行）。
